# Architecture

- Render the Finale through a shared championship card for the desktop and dedicated mobile Events layouts, so its presentation and action availability remain consistent without altering regular-season cards.
- Keep championship display details separate from standings and qualification calculations; published event information must not change scoring behavior.
- Centralize championship content, player IDs, group assignments, and optional future results in the presentation-only Finale configuration; the dedicated page and shared card consume it so updates stay consistent without connecting scoring data.
